# Codex AutoPro

[English](README.en.md) · [Skill 规则](SKILL.md)

让 Codex 按任务需要安排网页版 GPT-6 Pro 分析问题、编写代码或完成具体产出，再取回、核验并落地。具体工作和交付要求由 Codex 决定，不限于咨询答疑。

- 复杂分析或实现工作能受益时自动协作，无需事先批准；可对同一问题作必要追问，明确发送失败最多自动重试一次。
- Codex 提供必要上下文并明确交付物；本地修改、验证和 Git 提交由 Codex 执行，始终遵守原任务授权。
- 按任务需要上传代码文件、图片、文档等资料；资料较多时可整理成 ZIP，排除密钥和无关内容。
- 长任务交给宿主定时检查，保存完整回答和会话链接。
- 非简单问题思考不足两分钟或计时无法确认时，暂停采纳、交由用户检查。这是自定义检查规则，不是模型质量或内部路由的证明。

## 安装

将仓库克隆到个人 Skill 目录：

```sh
git clone https://github.com/ByronZhang1021/codex-autopro.git ~/.agents/skills/codex-autopro
```

## 使用

默认由 Codex 按任务需要自动使用，也可显式调用；用户指定的禁用、次数和资料限制优先。

```text
$codex-autopro 请 GPT-6 Pro 审查这个方案。只发送一次，结合你的核验报告结论。
```

也可安排具体实现，例如：“请 Pro 根据相关代码完成这个修复并给出补丁，由你核验、应用和验证。”

需要宿主提供浏览器控制、已登录且能选择目标模型的账户；无人值守等待还需要定时调度和浏览器恢复能力。Skill 本身不提供这些能力，缺失时会明确报告。

默认使用中文，可要求切换英文；上方 English 链接提供英文说明。正常结束后保存结果、删除检查自动化并关闭咨询标签页；异常时保留网页供检查。

消耗网页账户额度和 Codex 用量，不调用模型 API。独立社区 Skill，非 OpenAI 官方集成。
